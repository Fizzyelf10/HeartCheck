            How it works

            1

            You enter values

            Age, sex, chest pain, blood pressure and cholesterol are enough. Test results like max heart rate improve accuracy.

            2

            Spring Boot validates

            The Java backend checks every value is in a realistic range before anything reaches the model.

            3

            The model predicts

            A Python service runs a tuned scikit-learn model. Missing values are filled with typical values learned from the training data.

            4

            You get an explanation

            Each input is swapped with a typical value to measure how much it pushed your risk up or down.

                Frequently asked questions

                Where do I find these values?

                Blood pressure can be measured at home or a pharmacy. Cholesterol and fasting blood sugar come from a routine blood test. Max heart rate, ST depression, slope, vessels and thalassemia come from an exercise stress test, ECG, fluoroscopy or a thallium scan. If you don't have them, choose Not sure.

                Why does "no chest pain" sometimes increase the risk?

                The training data came from patients referred to a cardiology clinic. Many of those with confirmed disease had no typical chest pain ("silent" disease), so the model learned this pattern. It reflects that clinic population, not the general public.

                How accurate is it?

                On patients it never saw during training, the model reaches the ROC-AUC and accuracy shown above. That sounds high, but the dataset is small (303 patients from one US hospital in 1988) and the model was never clinically validated.

                Is my data stored?

                No. Values are sent to the model to compute the estimate and are not saved on the server. The "Recent checks" list lives only in your own browser and you can clear it anytime.

                Can I use mmol/L for cholesterol?

                Yes. Use the unit switch next to the cholesterol field. Values are converted to mg/dL (× 38.67) before being sent to the model.
